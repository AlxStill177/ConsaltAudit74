# Аудит Консалт

Статичный landing-page для аудиторско-консалтинговой компании в области бухгалтерского учета и налоговой отчетности.

## Публикация на GitHub Pages

1. Загрузите файлы проекта в репозиторий GitHub.
2. Откройте `Settings` → `Pages`.
3. В `Build and deployment` выберите `Deploy from a branch`.
4. Укажите ветку `main` и папку `/root`.
5. После публикации GitHub покажет ссылку на сайт.
